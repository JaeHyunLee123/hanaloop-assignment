# ADR 0002: 대시보드 기간 필터링 기능 추가 및 설계 결정

## 상태
승인됨

## 맥락
기존 탄소 배출 플랫폼 대시보드는 특정 달(단일 월)의 배출량 정보만 필터링하여 보거나, 혹은 전체 데이터를 누적하여 보는 단순한 구조였습니다. 사용자가 기간별 추이를 면밀히 모니터링하고 분석할 수 있도록, 대시보드 상단에 기간 필터(시작 연월 ~ 종료 연월 범위 지정 및 단일 월 지정 가능)를 적용하는 요건이 발생하였습니다.

이 기간 필터 요건을 만족하기 위해 프론트엔드 UI 컴포넌트 구조, API 쿼리 파라미터 구조, DB 집계 범위 및 기존 단일 월 API 파라미터와의 호환성 등을 결정해야 합니다.

## 결정 사항

### 1. API 쿼리 파라미터의 확장 및 범위 집계 적용
대시보드 통계 API `GET /api/dashboard-stats`가 시작 월(`startDate`)과 종료 월(`endDate`)을 쿼리 스트링으로 입력받을 수 있도록 확장합니다.
* Drizzle ORM의 `gte(emissionsTable.yearMonth, startDate)` 및 `lte(emissionsTable.yearMonth, endDate)` 조건식을 사용하여 DB 내의 배출 데이터를 기간 조건에 맞게 범위 필터링합니다.

### 2. 디폴트 기간 설정 (최근 12개월)
사용자가 명시적으로 기간을 지정하지 않고 대시보드에 진입했을 때, **현재 실제 시간 기준 당월 포함 12개월** (예: 2026년 6월 기준, `2025-07 ~ 2026-06`)의 배출 데이터를 기본값으로 보여줍니다.
* API 서버 측에서 `startDate`와 `endDate` 누락 시 현재 시간을 구하여 기본 최근 12개월 범위를 자동 주입해 줍니다.

### 3. 대시보드 컴포넌트별 필터 반응 규칙
* **수치 카드 (Total Emissions) 및 Scope, 회사, 수명주기 단계 차트**: 필터링된 기간 범위 내에 적재된 누적 탄소 배출량을 합산하여 연동 반영합니다.
* **단위당 PCF 카드 (Cradle to Gate/Grave)**: 제품 단위당 탄소 발자국은 DB 내에 적재된 동적 배출량과 관계없이 BOM 설계 및 배출계수 상수를 기준으로 한 이론적 고정값이므로 필터의 영향을 받지 않고 고정값을 보여줍니다.
* **월별 배출량 차트**: 사용자가 지정한 기간 범위(`startDate` ~ `endDate`)에 포함되는 월(Month)들만 동적으로 X축에 매핑하여 배출량 추이를 제공합니다.

### 4. 드롭다운 필터 UI 및 유효성 검증
대시보드 화면 상단에 "시작 월"과 "종료 월"을 선택할 수 있는 2개의 셀렉트 박스(YYYY-MM 포맷)를 배치합니다.
* **통합 제어**: 단일 월을 조회하려는 사용자는 두 드롭다운의 값을 동일하게 설정하면 되므로 모드를 별도로 분리할 필요 없이 일치된 인터페이스를 경험합니다.
* **유효성 검증**: 사용자가 종료 월을 시작 월보다 이전으로 선택하는 실수를 방지하기 위해, 시작 월이 선택되면 종료 월 드롭다운 내에서 시작 월보다 이른 연월 항목들은 선택 불가능(`disabled`) 처리합니다.
* **선택 가능 범위**: 시작 월은 시드 데이터 시작 시점인 `2025-01` 고정값으로 시작하고, 종료 월은 실제 현재 날짜 기준의 당월까지 동적으로 증가하여 사용자에게 노출됩니다.

### 5. API 파라미터 하위 호환성 유지
기존에 구현되어 있던 `month` 단일 쿼리 파라미터를 그대로 호출하는 상황에 대비하여, `month`가 주어지는 경우 내부적으로 `startDate = month`, `endDate = month`로 자동 변환하여 단일 달 범위 조회가 동작하도록 하위 호환성을 완벽하게 제공합니다.

## 결과 및 트레이드오프

* **장점**: 
  * 단일 월 조회부터 장기적인 기간별 누적 조회까지 하나의 통합된 UI/API 구조를 활용하므로 구현의 일관성이 높습니다.
  * 프론트엔드에서 유효하지 않은 기간 입력을 사전에 원천 차단하여 사용자 사용성을 향상합니다.
  * 기존 API 연동 테스트 및 기능들이 깨지지 않고 안정적으로 동작하는 하위 호환성을 가집니다.
* **단위당 PCF 미반영 한계**:
  * 제품 설계(BOM) 상의 배출량 이론치는 고정이지만, 실제 기간별 탄소 배출량의 동적 변동에 따른 실질적인 단위당 발자국 분석에는 적용되지 않는 한계가 있습니다. 그러나 이는 현재 기획의 범위 및 고정 공식 구조를 수용하기 위한 합리적인 트레이드오프입니다.
